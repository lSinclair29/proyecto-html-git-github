# Guía para demostrar Git y GitHub en clase

## 1. HTML — construcción
El sitio está construido únicamente con HTML. Abrir `index.html` en el navegador y recorrer sus páginas.

## 2. Git — evolución del proyecto
Comandos para la demostración:

```bash
git status
git log --oneline --graph --decorate
```

Para demostrar un cambio nuevo:

```bash
git status
git add .
git commit -m "Actualiza contenido para demostración"
```

## 3. GitHub — repositorio remoto
Repositorio:
`https://github.com/lSinclair29/proyecto-html-git-github`

Luego mostrar en GitHub:
- Archivos del proyecto.
- Historial de commits.
- README.
- Rama `main`.

## Flujo que deben explicar

HTML → construimos el proyecto.  
Git → registramos cómo evoluciona.  
GitHub → alojamos y compartimos el repositorio.

## Importante
El sitio web usa solamente HTML. Git y GitHub administran el código, pero no agregan diseño ni funcionalidades web al proyecto.
