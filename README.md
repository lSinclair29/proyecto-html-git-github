# Sistema de Gestión de Casos

Proyecto web para registrar, consultar y dar seguimiento a solicitudes de servicio técnico.

## Páginas
- `index.html`: presentación general del sistema.
- `casos.html`: listado de casos.
- `nuevo-caso.html`: registro de una solicitud.
- `detalle-caso.html`: detalle de un caso.
- `contacto.html`: formulario de contacto.
- `confirmacion.html`: confirmación de envío.

## Tecnologías del ejercicio
- HTML para la estructura del sitio.
- Git para el control de versiones.
- GitHub para alojar y presentar el repositorio.
