¿Qué es nuestro proyecto?

El Sistema de Gestión de Casos es una propuesta web orientada al registro, consulta y seguimiento de solicitudes relacionadas con servicio técnico. Su objetivo es reunir en un mismo lugar la información principal de cada caso, desde los datos del cliente y del equipo hasta el tipo de solicitud, prioridad y estado.

¿Qué problema buscamos resolver?

Cuando la información de servicio técnico se maneja de forma dispersa, resulta más difícil consultar el estado de una solicitud, identificar los datos del equipo o dar seguimiento a los casos pendientes. Este sistema organiza esa información mediante un flujo sencillo y fácil de consultar.

Funciones principales

  • Registrar nuevos casos de servicio técnico.
  • Consultar los casos existentes.
  • Visualizar el detalle de cada solicitud.
  • Clasificar los casos por tipo, prioridad y estado.
  • Registrar información del cliente y del equipo.
  • Adjuntar una referencia de evidencia al momento de crear un caso.

Flujo del sistema

  1. El usuario registra los datos del cliente y del equipo.
  2. Describe el problema o solicitud.
  3. Selecciona el tipo de caso y su prioridad.
  4. El caso queda identificado para su consulta y seguimiento.
  5. El estado permite conocer si está abierto, en revisión, en espera o cerrado.
